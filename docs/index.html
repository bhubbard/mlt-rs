mlt-rs — Memory-Safe Multimedia Authoring & NLE Framework in Pure Rust

mlt-rs is a safe Rust reimplementation of the MLT Multimedia Framework that powers open-source video editors like Shotcut and Kdenlive. It provides a modular producer-filter-tractor-consumer pipeline for frame-accurate multi-track compositing, XML project serialization, and real-time audio/video routing.

Rust SDK & melt CLI Quickstart

CLI Usage (melt)
# Play an MLT project file
melt project.mlt --profile hd1080p30

# Render multi-track project to destination
melt project.mlt -consumer render_output.mp4

# Generate color clip on vertical TikTok profile
melt color:red --profile vertical --out 90
Rust Programmatic API
use mlt_rs::{Tractor, Playlist, ClipProducer, Profile, DissolveTransition, TractorTransition};

fn main() -> anyhow::Result<()> {
    let profile = Profile::hd_1080_30p();
    let mut tractor = Tractor::new("timeline");

    let mut track0 = Playlist::new("v1");
    track0.append(Box::new(ClipProducer::new("c1", "shot1.mp4", 0, 59)), 0, 59);

    tractor.add_track(track0);
    let frame = tractor.get_frame(15, &profile)?;
    println!("Composited frame size: {}x{}", frame.width, frame.height);
    Ok(())
}
